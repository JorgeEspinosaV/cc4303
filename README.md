# Actividades de Redes — CC4303

Repositorio de actividades prácticas desarrolladas para el curso **Redes (CC4303)** de la Universidad de Chile.

El trabajo reúne implementaciones y análisis de distintos protocolos y mecanismos de comunicación en redes, desarrollados principalmente en Python.

## Contenidos del repositorio

### Actividad 1 — HTTP

Implementación y análisis de comunicación mediante el protocolo HTTP.

Se trabajó con el envío de solicitudes, recepción de respuestas y comprensión del intercambio de información entre cliente y servidor.

### Actividad 2 — DNS

Implementación y análisis del sistema de resolución de nombres DNS.

Se abordó la traducción de nombres de dominio a direcciones IP y el funcionamiento general de las consultas DNS.

### Actividad 3 — Stop-and-Wait

Implementación de un protocolo confiable basado en Stop-and-Wait.

Se trabajó con:

- Envío de paquetes
- Confirmaciones
- Temporizadores
- Retransmisiones
- Manejo de pérdidas

### Actividad 4 — Control de congestión

Implementación y análisis de mecanismos de control de congestión.

El objetivo fue estudiar cómo adaptar el envío de datos según el estado de la red y reducir pérdidas o saturación.

### Actividad 5 — Forwarding

Estudio del reenvío de paquetes y de las decisiones que toman los routers para dirigir el tráfico hacia su destino.

### Actividad 6 — Fragmentación

Análisis de la fragmentación de paquetes IP cuando su tamaño supera la unidad máxima de transmisión de una red.

### Actividad 7 —BGP
